# 第三问程序结构与运行

需要 Python 3.10 或更新版本，仅使用标准库。所有命令在本目录执行。

| 文件 | 职责 |
| --- | --- |
| `basic_sim.py` | 官方基础接口，保持原样 |
| `algorithm.py` | 算法、默认参数、参数校验和两个环境共用的执行器 |
| `sss.py` | 离线环境、案例生成、局后评价、批量测试和统一日志 |
| `main.py` | 官方模拟器执行入口 |
| `iterator.py` | 可调参数空间、历史结果比较、候选生成 |
| `auto_test.py` | 自动循环离线测试与参数迭代 |
| `quest3.py` | 兼容旧入口，转到 `main.py`，不保留第二份算法 |

## 手动执行

官方模拟器：先在界面启动相应测试，等待接口就绪，再运行：

```powershell
python main.py
```

程序读取 `params.json`；文件不存在时使用 `algorithm.py` 默认参数。
`main.py` 不启动或重开官方测试。程序行为日志在 `output/official/`；
正式测试的加密日志仍需从官方模拟器导出。

离线测试，先仅测试当前参数：

```powershell
python sss.py --runs 10 --current-only
python iterator.py --candidate-count 4
python sss.py --runs 10
python iterator.py --candidate-count 4
```

也可先运行 `iterator.py` 生成候选，再运行 `sss.py`，第一批即可比较多组参数。
`sss.py` 默认测试当前参数及 `candidates.json` 中的全部候选。
`--runs` 是**每组参数**的案例数，不是所有参数组合的合计局数。

## 自动循环

```powershell
python auto_test.py --rounds 5 --runs 10 --candidate-count 4 --seed 2026
```

表示执行 5 轮，每轮比较当前参数与 4 组候选，每组 10 局，预计共 250 局。
自动脚本先生成候选，然后每轮依次：

1. 对同一组案例执行当前参数及候选参数。
2. 将每局结果与动作序列保存到统一 JSON。
3. 调用迭代器读取已完成批次，选择参数并生成下一轮候选。

每轮使用新的案例种子；同一轮所有参数使用相同案例。
`--runs` 至少为 10，以提供至少 2 个验证案例。
`Ctrl+C` 终止循环，已完成的局保留；未完成批次标记为中断，不参与选参。
重新启动会开始新批次，不会从中断局继续。
这三个离线入口均不导入或调用 `basic_sim.py`。

## 文件输出与参数选择

- `output/offline_runs.json`：唯一的离线日志，包含批次、每局参数快照、案例编号、
  算法/环境版本、评价指标、完整动作反馈和参数迭代记录。
- `params.json`：在离线比较和验证中合格的当前参数，不等于官方效果保证。
  没有足够结果或没有合格参数时，不生成或不更新此文件。
- `candidates.json`：下一批尚待验证的参数，不直接替代官方运行参数。

每完成一局原子替换日志文件。不要同时运行多个写入相同文件的入口；如要隔离实验，
使用 `--log`、`--params`、`--candidates` 指向不同文件。三种离线入口都支持这些参数。
大量局数配合完整动作日志会使单个 JSON 增长，读写时会整体载入。

每第五个案例用于验证，其余用于训练比较。迭代器只比较当前算法和环境版本的
最新完整批次，并要求当前参数与候选有相同的案例集合。至少需要 3 个训练案例和
2 个验证案例。训练优胜者必须全部清除；验证也必须全部清除，且验证耗时目标
相对无失败的当前参数不得退化超过 2%，才能替换参数。

耗时目标是 `0.8 × 平均虚拟总耗时 + 0.2 × 第90百分位虚拟总耗时`。
候选通过轮换的单参数邻域搜索与多参数随机变异生成。迭代器本身不运行模拟，
不将未经测试的候选标记为已验证。尚未提供数据时只能提出候选，不能得出优化效果。

可优化参数及离散范围在 `iterator.SEARCH_SPACE`；完整默认参数在
`algorithm.StrategyConfig`。题目物理常量、方向误差安全边界不参与优化。
格子大小仍须满足清除覆盖约束，搜索点半径须满足七点覆盖约束。

离线环境的目标分布和固定空间误差场属于模拟假设。它复现四个操作接口和物理计时，
不模拟官方服务器登录、HTTP 重试、倒计时或日志上传。

## 检查

`test_workflow.py` 使用替身函数检查批处理、参数选择、日志持久化，
不会执行搜索模拟或连接官方接口。
`test_quest3.py` 包含算法与离线环境的模拟测试，需明确准备测试时再运行。
